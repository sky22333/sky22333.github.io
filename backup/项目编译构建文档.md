
# PowerShell
解除脚本限制，执行完后重启PowerShell窗口生效。
```powershell
# 解除限制（当前用户）
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force

# 完全解除限制
Set-ExecutionPolicy Unrestricted -Scope CurrentUser -Force
```

### 一行命令添加目录到系统环境变量（PATH）

添加某个目录到系统PATH（以flutter为例），需要管理员权限，执行完需要重新打开PowerShell
```powershell
$dir = "D:\flutter\bin"; [Environment]::SetEnvironmentVariable("Path", $env:Path + ";$dir", "Machine")
```

查看当前系统PATH
```powershell
$env:Path
```

### 下载 Visual Studio 生成工具

下载后在`使用C++的桌面开发`菜单里勾选如下组件即可


### 安装Rust开发环境

下载地址：https://rust-lang.org/zh-CN/tools/install/

下载后双击安装，一路回车即可。

### 常用命令

初始化

```powershell
# 创建一个二进制项目（可执行程序）
cargo new mydemo

# 创建一个库项目（Library）
cargo new --lib mylibrary

# 当前目录初始化项目
cargo init
```

编译与运行
```powershell
cargo run                     # 编译并运行（最常用）
cargo run --release           # Release 模式运行（更快）
cargo build                   # 只编译
cargo build --release         # Release 模式编译
cargo check                   # 快速检查错误（推荐开发时使用，速度快）
```

依赖管理
```powershell
cargo add serde               # 添加依赖（最新推荐方式）
cargo add serde --features derive
cargo remove serde            # 移除依赖
cargo update                  # 更新依赖到最新版本
```

清理与发布
```powershell
cargo clean                   # 清理 target 目录
cargo clippy                  # 运行 Clippy 代码检查
cargo fmt                     # 代码格式化
cargo publish                 # 发布到 crates.io
```
### 项目里配置加速

项目根目录添加`.cargo\config.toml`配置字节跳动的Rust镜像

```
[source.crates-io]
replace-with = 'rsproxy-sparse'
[source.rsproxy]
registry = "https://rsproxy.cn/crates.io-index"
[source.rsproxy-sparse]
registry = "sparse+https://rsproxy.cn/index/"
[registries.rsproxy]
index = "https://rsproxy.cn/crates.io-index"
[net]
git-fetch-with-cli = true
```

`git-fetch-with-cli = true`代表使用系统的Git工具

# 安卓开发环境

安装IDE下载地址：https://developer.android.com/studio

中文汉化包：https://github.com/sollyu/AndroidStudioChineseLanguagePack

### 汉化

1. 安装汉化包  
   `右上角设置 ⚙️` → `Plugins…` → `Plugins页面的设置 ⚙️` → `Install Plugin from Disk…` → 选择汉化包 → OK → 重启 IDE

2. 切换语言和地区  
   `右上角设置 ⚙️` → `Settings…` → `Appearance & Behavior` → `System Settings` → `Language and Region` → 语言选`简体中文`、地区选`China Mainland`→ OK → 重启 IDE


### Gradle国内镜像配置

在项目根目录下的`settings.gradle`（或`settings.gradle.kts`）中添加：
```
gradlepluginManagement {
    repositories {
        maven { url 'https://mirrors.aliyun.com/gradle-plugin' }
        maven { url 'https://mirrors.cloud.tencent.com/gradle-plugin' }
        google()
        mavenCentral()
    }
}

dependencyResolutionManagement {
    repositories {
        maven { url 'https://mirrors.aliyun.com/maven' }
        maven { url 'https://mirrors.cloud.tencent.com/maven' }
        google()
        mavenCentral()
    }
}
```

### 配置代理

`项目根目录/gradle.properties` 追加：
```
systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=10808
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=10808
# 不走代理的地址
systemProp.http.nonProxyHosts=*.aliyun.com|*.tencent.com
```

### 缓存清理

| 目的 | 操作 |
|---|---|
| 清 IDE 缓存 | File → Invalidate Caches （使缓存失效...）|
| 清 Gradle 依赖缓存 | `~/.gradle/caches/` |
| 清 Gradle 分发 | `~/.gradle/wrapper/dists/` |
| 清构建产物 | `./gradlew clean` 或删除 `app/build` 目录 |

 **`gradlew`命令临时变量设置**
```
$env:JAVA_HOME = "IDE安装目录\jbr"
```


### Gradle Wrapper下载加速

打开项目中`gradle/wrapper/gradle-wrapper.properties`修改：
```
# 阿里云
distributionUrl=https\://mirrors.aliyun.com/gradle/distributions/gradle-9.5.0-all.zip
```

# Go 开发环境

下载地址：https://go.dev/doc/install

### Go 国内镜像与代理配置（PowerShell 命令）

国内镜像
```powershell
go env -w GOPROXY="https://goproxy.cn,direct"
```

恢复官方镜像


### Go代理

```powershell
go env -w HTTP_PROXY="http://127.0.0.1:10808"
go env -w HTTPS_PROXY="http://127.0.0.1:10808"
```

移除代理
```powershell
go env -w HTTP_PROXY=""
go env -w HTTPS_PROXY=""
```
查看全局配置
```powershell
go env
```

### 常用命令
```powershell
go mod init myproject                         # 初始化模块
go mod tidy                                   # 清理和更新依赖（最常用）

go run .                                      # 运行当前项目

go build -o app.exe                           # 指定输出文件名

go test -v                                    # 运行测试
go fmt ./...                                  # 格式化代码
go vet                                        # 静态检查
go mod tidy                                   # 整理依赖

go version                                    # 查看版本
go env                                        # 查看环境变量
```

质量检查
```
go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest
golangci-lint run
```
```
go install honnef.co/go/tools/cmd/staticcheck@latest
staticcheck ./...
```

交叉编译
```powershell
# 交叉编译 Windows 64位
$env:GOOS="windows"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"; go build -ldflags="-s -w" -o myapp.exe

# 交叉编译 Linux 64位
$env:GOOS="linux"; $env:GOARCH="amd64"; $env:CGO_ENABLED="0"; go build -ldflags="-s -w" -o myapp

# 交叉编译 Android ARM64
$env:GOOS="android"; $env:GOARCH="arm64"; $env:CGO_ENABLED="0"; go build -ldflags="-s -w" -o myapp
```

```bash
GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build -ldflags="-s -w" -o myapp
```

# 前端开发环境

nodejs下载地址：https://nodejs.org/zh-cn

### 国内镜像
```powershell
# 设置淘宝镜像
npm config set registry https://registry.npmmirror.com

# 恢复官方镜像
npm config set registry https://registry.npmjs.org
```

### 代理
```powershell
# 设置代理
npm config set proxy http://127.0.0.1:10808
npm config set https-proxy http://127.0.0.1:10808

# 取消代理
npm config delete proxy
npm config delete https-proxy
```

### 常用命令

`axios`是包名
```powershell
npm i                              # 安装依赖
npm install axios                  # 安装依赖（生产环境）
npm install axios --save-dev       # 安装开发依赖
npm install axios@latest           # 安装最新版本

npm uninstall axios                  # 卸载包
npm cache clean --force              # 清理缓存

npm start                            # 运行 start 脚本
npm run dev                          # 运行 dev 脚本
npm run build                        # 运行 build 脚本

npm list                             # 查看已安装依赖

npm install -g pnpm                  # 全局安装工具（pnpm包管理器）
npm update -g                        # 更新全局包
npm -v                               # 查看 npm 版本
```
